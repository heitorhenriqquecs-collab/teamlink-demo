# TeamLink — demonstração

Demonstração pública e isolada de um gerenciador de equipes e projetos. Pessoas, tarefas e organizações exibidas são fictícias. As alterações ficam apenas no navegador.

## Testar

[Abrir a demonstração no portfólio](https://heitt.portalsgi.dev.br/teamlink-demo/)

O código publicado contém somente a interface demonstrativa. Banco de dados, backups, credenciais e dados da versão privada não fazem parte deste repositório.

## Privacidade

A demonstração não usa conta, anúncios, Google Analytics ou pixels de rastreamento. Ela usa armazenamento local apenas para manter as alterações feitas na simulação. A política completa está disponível no [portfólio](https://heitt.portalsgi.dev.br/legal/).
